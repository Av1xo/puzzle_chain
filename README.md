# PUZZLE

Вітаю, це тестове завдання для вступу в програму стажування від PortaOne.

## Опис завдання:

Задача — скласти найбільший однорядний цифровий пазл.

Чи любите ви пазли? Давайте складемо з вами цифровий пазл, де елементами з'єднання будуть перші або останні **ДВІ** цифри. Для спрощення завдання будемо використовувати однорядний пазл, де його фрагменти можуть розміщуватись тільки слідуючи один за одним.

Наприклад, маємо такі рядки із числами:
`608017`, `248460`, `962282`, `994725`, `177092`

**Рішення:**
Аналізуючи кінцеві частини, можна скласти такий ланцюжок:
`248460` & `608017` & `177092` -> `2484(60)80(17)7092`

Таким чином найбільша послідовність і відповідь буде: **24846080177092**

Текстовий файл має 142 фрагменти, що повинні складатися тільки із цифр! Визначте найбільшу (найдовшу) послідовність для цих фрагментів.

Файл можна завантажити за [посиланням](https://dl.portaone.com/pluginfile.php/75649/mod_quiz/intro/source.txt).

Кожен фрагмент має бути використаний тільки 1 раз.

### Обмеження
Існують лише такі обмеження, які слід враховувати при виборі способу вирішення задачі:

1. **Обмеження #1:**  
   Будь-яка людина повинна мати можливість скористатися вашим методом. Це означає, наприклад, якщо для вирішення завдання Ви використовували свою власну програму, то будь-яка інша людина повинна мати можливість її скомпілювати/запустити і т.д.; якщо Ви використовували сторонні програми/утиліти, то будь-яка людина повинна мати можливість їх також встановити та користуватися; також будь-яка людина може взяти файл із зовсім іншим набором фрагментів і отримати із них відповідну послідовність.

2. **Обмеження #2:**  
   При вирішенні задачі не можна використовувати нелегальне програмне забезпечення (пропрієтарне ПЗ, яке зазнало злому, піратські копії ПЗ, тощо). Також якщо ви запозичили ідею рішення, ПЗ або вихідні джерела (або якусь їх частину) у друга/колеги/в інтернеті/де-завгодно, то згадайте джерело.

### Інструкція з користування (Меню CLI)
Після запуску ви побачите інтерактивне меню з наступними опціями:

    1 Load data from file: Завантаження текстового файлу з фрагментами пазлів (наприклад, source.txt).

    2 Find longest chain: Запуск алгоритму пошуку найдовшого ланцюжка.

        Автоматично перевіряє компоненти зв'язності.

        Застосовує оптимальний алгоритм Гірхольцера (якщо існує Ейлерів шлях) або паралельний DFS із відсіканням гілок.

    3 Show result: Виводить знайдену найдовшу цифрову послідовність у консоль.

    4 Validate chain: Перевіряє коректність сформованого ланцюжка (відсутність повторного використання фрагментів та правильність з'єднання стиків).

    5 Visualize chain: Зберігає графічну схему побудованого ланцюжка пазлів у PNG-файл (за замовчуванням chain.png).

    6 Exit: Вихід з програми.

### Використання як модуля (Python API)

Ви також можете використовувати модуль рішення безпосередньо у своєму коді:

```python
from solver import solve

with open("source.txt", "r") as f:
    raw_data = f.readlines()

result = solve(raw_data)
print(f"Результат: {result}")
```
